                        🚀 HOW TO GET STARTED
================================================================================

STEP 1: Setup Environment (1 minute)
   $ cd /home/claude/matchremote
   $ cp .env.example .env.local

STEP 2: Get Supabase Credentials (2 minutes)
   - Create account at https://supabase.com
   - Create new project
   - Copy URL and API keys to .env.local

STEP 3: Setup Database (1 minute)
   - Go to Supabase SQL Editor
   - Run: lib/db/schema.sql
   - Database tables created!

STEP 4: Run Locally (1 minute)
   $ npm run dev
   - Open http://localhost:3000
   - Take the quiz
   - View your matches

STEP 5: Deploy (Optional - see DEPLOYMENT_CHECKLIST.md)
   - Push to GitHub
   - Connect to Vercel
   - Add environment variables
   - Set custom domain

See QUICKSTART.md for detailed steps and troubleshooting.
